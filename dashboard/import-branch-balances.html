Загрузить остатки филиалов

Отдельный Excel — не меняет реестр филиалов с координатами. Связка только по Код БХМ ↔ локал код филиала (по названию — нет). Пустые ячейки и - = нет данных; 0 = ноль. Каждая загрузка хранится отдельно: 1-й импорт, 2-й импорт и дальше. Новая не стирает старую и не смешивается с ней. На карте открыт последний импорт.
